# Networking-Labs

Simulated networking projects focused on Cisco technologies, enterprise networking, troubleshooting, and practical administration.

I am a Networking student using this repository to **practice, document, and progressively develop my networking skills through hands-on labs**. Each laboratory is designed not only to practise configuration, but also to document the topology, addressing plan, configuration process, verification steps, and troubleshooting procedures.

The main objective of this repository is to build a structured collection of practical networking exercises that can be used as a reference for my own learning and as a record of my technical progression.

## What you will find here

This repository contains:

* Practical networking laboratories based on real-world enterprise scenarios.
* Network topologies and addressing plans.
* Cisco device configurations and CLI commands.
* Configuration manuals and step-by-step procedures.
* Connectivity and troubleshooting tests.
* Verification commands and expected results.
* Technical documentation for each laboratory.
* Increasingly complex network designs as new concepts and technologies are introduced.

The laboratories will progressively become more advanced as I develop my networking knowledge. Early labs focus on fundamental concepts such as **VLANs, switching, routing, subnetting, and inter-VLAN routing**, while future labs will incorporate more advanced technologies, architectures, redundancy mechanisms, security features, and troubleshooting scenarios.

## Lab Environment

The primary platform used for these laboratories is **GNS3**, combined with:

* GNS3 VM for virtualization and network emulation.
* Cisco IOS images and appropriate Cisco licensing.
* Virtual and simulated enterprise network topologies.
* Additional networking platforms as my knowledge and experience develop.

Cisco technologies will be the main focus of the repository initially. However, I plan to progressively incorporate other vendors and platforms such as **Fortinet, Aruba, and other networking technologies** to gain experience working with different network architectures, operating systems, and vendor-specific implementations.

## Learning Approach

The goal is not simply to complete predefined configurations, but to understand **why** each technology is used, how different network components interact, and how to troubleshoot problems when the expected behavior is not achieved.

As I progress through my networking studies, the laboratories in this repository will evolve from basic configurations into more complex and realistic enterprise scenarios.

This repository will therefore serve as both a **learning environment and a technical portfolio**, documenting my progression from fundamental networking concepts toward more advanced network engineering skills.
